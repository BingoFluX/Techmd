## 8.常用命令

### 1.内置命令

```bash
/status  	#查看状态
/side		#侧边对话，不污染主对话，目前codex无法回溯
/model		#切换模型
/compact	#压缩上下文 "不会丢失关键上下文，它会智能保留重要的代码片段和决策信息，仅压缩冗余的对话轮次"
```
